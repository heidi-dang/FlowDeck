# FlowDeck v2.0.0-alpha.3 — Release Candidate

## Summary

Alpha.3 is a corrected prerelease candidate following the immutable, unpublished alpha.2 tag-triggered workflow failure. The correction makes SQLite schema validation deterministic across runners with and without a `sqlite3` executable and adds a non-publishing preflight for the exact npm artifact.

## Included v2 work

- Autonomous execution intelligence with Master Plan completion at 100%.
- Dependency-aware workstream execution with isolated worktrees and ownership enforcement.
- Adaptive token control, agent performance intelligence, and gated authoritative routing.
- Optional worktree-aware FDX runtime and fallback behavior.
- Production observability, B1–B14 benchmark coverage, restart recovery, and security hardening.

## Release-path correction

The alpha.2 tag remains immutable and unpublished. Alpha.3 uses the discovered SQLite CLI through argument-safe subprocess calls and resolves schema resources from the validator module, so tag-triggered CI and local fallback validation exercise the same behavior. The release workflow now runs a credential-free pack/install/doctor preflight before registry checks and publication.

## Benchmark caveat

The historical pre-benchmark baseline predates the current benchmark surface; no unsupported historical performance improvement claim is made.

## Status

This is an unpublished release candidate. No alpha.3 tag, npm publication, GitHub release, or deployment is created by this branch.
