# FlowDeck v2.2.4

FlowDeck v2.2.4 is a production maintenance and hardening release that resolves multi-agent subagent retry loop pathologies, circuit breaker strategy enforcement, and false-positive guard blocks discovered during comprehensive runtime auditing.

## Key Changes & Fixes

1. **Auto-Forward Native Read to `fdx-read` (`src/hooks/tool-guard.ts`)**:
   - Replaced the previous advisory rejection string in `tryFdxRedirect` with silent in-place argument adaptation (`read` / `read_file` args adapt cleanly to `fdx-read`).
   - Prevents specialist subagents from entering 300+ turn retry loops when calling native read operations under enforced FDX redirection.

2. **Tool-Error Circuit Breaker Strategy (`src/services/orchestrator-guard-strategy-circuit.ts`)**:
   - Integrated per-session tool error tracking (`recordToolError`, `clearToolErrorCounts`) enforcing a deterministic 3-strike hard limit on repeated identical tool errors.

3. **Shell Command Classifier Refinement (`src/services/shell-command-classifier.ts`)**:
   - Made `cd <dir>` prefixes transparent at the start of compound inspection pipelines (`cd /path && git status`, `cd /path && git remote -v`).
   - Removed blanket `~` path-traversal blocking in `hasPathTraversal`, resolving false-positive blocks on non-sensitive cache inspections (`ls ~/.cache/`) while preserving sensitive directory protections (`.ssh`, `.env`, `.pem`, credentials).

4. **Disposable Temporary Fixture Cleanup Scoping (`src/hooks/tool-guard.ts`)**:
   - Permitted `rm -rf` commands when all target paths are strictly scoped inside temporary directories (`/tmp/`, `/var/folders/`, `$TMPDIR`), allowing tester and debug subagents to tear down disposable fixtures cleanly.

5. **Token Optimization & Opt-In `sequentialThinking` MCP (`src/mcp/index.ts`)**:
   - Defaulted `sequentialThinking` MCP server to opt-in (`FLOWDECK_ENABLE_SEQUENTIAL_THINKING=true`), eliminating ~1,500 tokens of redundant schema overhead per model turn.

6. **FDX Tool Priority Subagent Prompt Hardening (`src/agents/debug.ts`, `src/agents/security-auditor.ts`)**:
   - Injected explicit hard rules directing specialist subagents to immediately switch to `fdx-read` / `fdx-grep` on file access.

7. **Specialist Subagent Turn Budget Limits (`src/services/heidi-task-state.ts`)**:
   - Added `maxChildTurns` (default 60) and per-child turn count tracking with `incrementChildTurn()` and `isChildOverBudget()` to prevent runaway token spend.
