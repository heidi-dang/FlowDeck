# FlowDeck v2.0.6

## Fixed & Hardened

- **Semantic Heidi Liveness Watchdog**: Added a robust semantic watchdog that actively detects and recovers from genuinely stalled sessions where Heidi has unresolved tasks but no active tool, provider, or child operations.
- **Provider Replay Sanitation**: Hardened in-place provider history replay sanitization to ensure reasoning-only and zero-part completion artifacts are safely stripped or marked with safe neutral placeholders.
- **Provider Recovery Limits**: Bounded stage-2 provider recovery (e.g. for `INVALID_ARGUMENT`) ensuring safe failure termination without infinite retries.
- **Async Resource Lifecycles**: Completely eliminated post-dispose test leakage across Windows, macOS, and Linux by strictly clearing watchdog timers, pending continuation promises, child session metadata, and orchestration states on plugin disposal.
- **Continuous Integration Stability**: Resolved exact-SHA CI packaging/parsing bugs where chunked tarball extraction streams produced transient `SyntaxError: Unterminated string in JSON` across Build & Validate gates.
