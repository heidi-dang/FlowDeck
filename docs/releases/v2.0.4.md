# FlowDeck v2.0.4

**Release Date:** 2026-08-16

## What's New

### Productive Autonomous-Session Limits Raised to ≥100

All session quotas bumped from conservative defaults (15-20) to 100+, enabling long uninterrupted coding sessions:

| Quota | v2.0.3 | v2.0.4 |
|---|---|---|
| `maxWritesPerAgent` | 15 | **100** |
| `maxDelegations` | 20 | **100** |
| `toolPipeline.maxCalls` | 20 | **100** |
| `scheduler.defaultBudget` | 20 | **100** |
| `governance.maxToolCalls` | 200 | 200 (unchanged) |

These limits are configurable via `.flowdeck.json` — the defaults just no longer prematurely terminate productive sessions.

### Doctor: Autonomy Limits Check

`flowdeck doctor` now reports the configured autonomy quotas under `heidi.autonomy_limits`, confirming they meet the ≥100 threshold for long sessions.

## Upgrade

```bash
npm install -g @heidi-dang/flowdeck@latest
```

npx @heidi-dang/flowdeck install
