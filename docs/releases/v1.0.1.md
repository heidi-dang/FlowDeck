# FlowDeck v1.0.1 — First-Run Reliability

FlowDeck 1.0.1 is a reliability patch restoring first-run installs: the streamed `curl | bash` installer no longer aborts on an unbound variable, and the packaged Doctor no longer fails healthy installs by checking repository-only files that npm tarballs do not ship.

## What's Fixed

### Streamed Installer — `DOCTOR_PROFILE` unbound variable
- The v1.0.0 installer referenced `DOCTOR_PROFILE` at the pre-install doctor gate under `set -euo pipefail` without initialising it, aborting **every** plain `curl ... | bash` install with `DOCTOR_PROFILE: unbound variable`.
- `DOCTOR_PROFILE=""` is now initialised in the same declaration block as the other doctor flags, before the first guarded use.
- Regression covered by `tests/installer/streamed-installer.test.ts`, which streams the real `install.sh` through `bash -s` with stubbed `node`/`npm` on PATH: all streamed installs exit 0 with "FlowDeck installation completed".

### Packaged Doctor — false failures on healthy installs
- The packaged Doctor validated repository-only artefacts (`tsconfig.json`, `uninstall.sh`, `.gitignore`) that are **not shipped** in the npm tarball, reporting errors on healthy npm/packed installs.
- New environment classifier `classifyDoctorEnvironment` (`source-checkout` | `local-repo` | `npm` | `packed` | `unknown`) with `isRepoLikeEnvironment` failing closed on unknown layouts.
- Repository-only checks now report `skipped` on npm/packed installs while remaining active on source checkouts.
- The `security.secret_redaction` check is now a **behavioural probe**: it imports `redactSecrets` from the packaged bundle (`dist/index.js`) or the source module and asserts a synthetic token is redacted — never a hardcoded pass.
- `redactSecrets` / `containsSecrets` are exported from the package entry point for consumers.

### CI Gates
- New packed tarball doctor gate: extracts the tarball, runs the Doctor on the extracted layout, asserts exit 0, zero errors, and repo-only checks skipped.
- Packed CLI doctor exit checks tightened from `-gt 1` to `-ne 0` in the packed-cli matrix.
