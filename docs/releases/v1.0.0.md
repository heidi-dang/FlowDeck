# FlowDeck v1.0.0 — The Orchestration Engine

FlowDeck 1.0 marks the first stable production release of FlowDeck: a governed multi-agent orchestration, code-intelligence, and CI lifecycle platform built for OpenCode.

## What's New

### Agent Orchestration
- **13 specialized agents**: `heidi` (default primary) plus 12 specialists — `orchestrator`, `planner`, `architect`, `researcher`, `mapper`, `backend-coder`, `frontend-coder`, `devops`, `tester`, `reviewer`, `security-auditor`, `debug-specialist`.
- **Heidi Primary Execution Policy**: heidi executes tasks directly and delegates only when delegation is justified, with depth-1 delegation and `task:deny` on delegates to prevent runaway agent chains.
- **Structured planning pipeline**: `/fd-task` → `/fd-review` → `/fd-execute` → `/fd-verify` → `/fd-done`, with persisted artifacts, checkpoints, and `/fd-resume` recovery.

### Code Intelligence — FDX Native CLI
- Rust-native `fdx` CLI with 14 subcommands: `read`, `search`, `grep`, `batch`, `impact`, `outline`, `diff`, `git`, `ls`, `tree`, `test`, `lint`, `context`, `decisions`.
- tree-sitter AST parsing across 5 languages and a dual-AST symbol diff engine.
- Automatic TypeScript fallbacks for every tool when the native binary is unavailable — the system stays fully functional without a Rust toolchain.

### Governance and Security
- **Command boundary** with typed process outcomes (`timeout`, `max_buffer_exceeded`, `executable_not_found`, `parse_rejected`, `authorization_rejected`) and hard-validated resource limits before spawn.
- **Executable allowlist** (`fdx`, `git`, `npm`, `bun`, `vitest`, `oxlint`, `tsc`, `node`) enforced with `shell: false` on all invocations.
- **Git read-only policy** blocking mutating subcommands at the validation layer.
- Structured audit events for every governance decision (block/warn/approve).

### CI Auto-Repair — PR Monitor
- Event-driven failure detection via `workflow_job:completed` webhooks.
- Root-cause classification and bounded automated repair with a circuit breaker (max 3 attempts per head SHA).
- Safety: SHA-based dedup, stale-head detection, fork-PR protection, prohibited paths (`.github/workflows/release.yml`, `.env`), and no auto-merge or auto-release.

### Durable Orchestration Runtime
- SQLite-backed event persistence with transactional outbox delivery.
- Optimistic concurrency via unit-of-work and versioned writers.
- Replay-safe execution and deterministic resource cleanup.

## Reliability

- **81.31% weighted aggregate line coverage** (threshold 80%).
- Full suite verified on Linux, macOS, and Windows; zero typecheck and lint errors.
- FDX native/TypeScript parity verified; Rust gates (fmt, clippy, tests) pass.
- **Zero vulnerabilities** across production and full dependency audits.

## Compatibility and Migration

- **No configuration migration required** from any `0.8.0-alpha.x` release — the schema is backward-compatible and the installer preserves existing registrations, `default_agent`, and JSONC comments.
- Node.js >= 20.0.0, OpenCode >= 1.4.0, Linux/macOS/Windows.
- Rust toolchain optional; required only for the native FDX CLI (TypeScript fallbacks ship in the package).

Upgrade with:

```bash
curl -fsSL https://raw.githubusercontent.com/heidi-dang/flowdeck/main/install.sh | bash
```

Then verify: `npx flowdeck doctor`
