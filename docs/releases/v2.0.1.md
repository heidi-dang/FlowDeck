# FlowDeck v2.0.1 Release Notes

**Date:** August 16, 2026  
**Version:** `v2.0.1`  
**Track:** Stable (`@latest`)

---

## Executive Summary

FlowDeck v2.0.1 is the official production release introducing **FlowDeck Doctor Repair Engine (`flowdeck doctor fix`)**, **Heidi UI/App Studio**, **Autonomous Browser Debugging & Real Chrome Integration**, and **Curated Skill Security Provenance**.

This release hardens machine health diagnostics, providing deterministic single-command auto-repair (`flowdeck doctor fix`) with post-repair verification, atomic configuration backups, and lock safety.

---

## Key Capabilities

### 1. FlowDeck Doctor Repair System (`flowdeck doctor fix`)
- **Comprehensive Machine Audit**: Inspects core installation integrity, Node/Bun runtimes, FDX native engine, Chrome/Chromium binaries, skills security lockfile, MCP connectivity, plugin registration, and permissions.
- **Deterministic Auto-Repair**: Automatically repairs permissions, pre-creates state directories, cleans up stale process lock/PID files, normalizes `opencode.json` plugin registration, updates skills lockfiles, restores native FDX shims, and repairs MCP configuration schemas.
- **Transaction Safety**: Performs timestamped backups (`.flowdeck/backups/doctor-repair-<timestamp>.json`) before mutating configuration files and executes atomic file writes with rollback protection.
- **Post-Repair Verification**: Re-evaluates Doctor health checks after repair passes to verify actual operational state before outputting health status.

### 2. Heidi UI/App Studio
- **UI Architect**: Constructs structured UI architecture models (screens, navigation, component requirements, data requirements, responsive strategy, design direction, interaction models) for multi-tier frontend applications.
- **Design-System Intelligence**: Indexes project design tokens, CSS custom properties, Tailwind settings, and existing components for **reuse-first** component selection.
- **Native UI Generator**: Generates clean React/Vite/Next components respecting project conventions, with bounded concept visual variants (`minimal/professional`, `premium/expressive`, `dense/productivity`).
- **Visual Critic & Refinement Loop**: Evaluates layout hierarchy, spacing, typography, contrast, accessibility, touch target sizes, and multi-viewport layouts (`390x844`, `768x1024`, `1440x900`). Implements circuit-breaker refinement loops to eliminate defects without infinite loops.
- **Heidi Design Mode**: Correlates browser element selection: `DOM Element → Semantic Target → React Component → FDX Symbol → Source File`, enabling natural-language edits with source-aware modification scope safety.
- **Full-Stack Builder**: Execution graph builder and provider-neutral support boundaries for Postgres, SQLite, MySQL, Supabase, Neon, Auth.js, Clerk, Vercel, Docker, and AWS.

### 3. Heidi Autonomous Browser Debugging
- Real Chrome/Chromium integration via CDP session adapter (`agent-browser`).
- Automated capture of console errors, network failures, DOM element targets, and visual snapshots.

### 4. Curated Skills Subsystem
- 65 validated skill modules with security provenance tracked in `src/skills/skills-lock.json`.
- Strict YAML frontmatter verification, line-count budgets, and description word-count enforcement.
