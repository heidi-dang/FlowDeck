# FlowDeck v2.0.0-rc.1

Date: 2026-08-14

Status: **RELEASE CANDIDATE (RC.1)**, published under `next` npm dist-tag.

## Overview

FlowDeck v2.0.0-rc.1 is the official release candidate for FlowDeck v2.0.0. It introduces persistent Heidi memory, cross-session recall, evidence-backed learning review, versioned learned skills, governed tool pipelines, durable scheduling, adaptive parallel execution engine, runtime identity verification, and hardened installer reliability.

## Major Heidi v2 Changes

- **Persistent USER/AGENT/REPO Memory**: Persistent architecture and conversation state graph in `.codebase/MEMORY.json` and SQLite storage.
- **Cross-Session FTS Recall**: `heidi-recall` tool searching archived session messages using SQLite FTS5 index.
- **Automatic Learning Review**: Evidence-backed candidate learning propose/review/approve/reject system via `heidi-learning`.
- **Versioned Learned Skills**: Reusable agent skills versioning and discovery via `heidi-skill`.
- **Governed Tool Pipelines**: Declarative pipeline execution across allowed tools via `heidi-tool-pipeline`.
- **Durable Scheduler**: Atomic occurrence claiming for cron/interval/once schedules via `heidi-scheduler`.
- **Runtime Identity Verification**: Self-reporting plugin identity (`FlowDeckRuntimeIdentity`) asserting loaded package version, PID, start time, and source classification.

## Parallel Execution Engine

- **Durable DAG & Dependency Scheduling**: Autonomous multi-specialist parallel DAG runner (`heidi-agents`).
- **Adaptive Concurrency & Token Reservations**: Token budget management and dynamic wave scaling.
- **Worktree & Failure Isolation**: Isolated git worktree per execution phase (`fdx-worktree`) with typed conflict detection.
- **Restart Recovery**: Persistence schema v11 supporting crash recovery and state resumption.

## Installer Reliability & Duplicate Plugin Repair

- **Stale OpenCode Cache Discovery**: Scans `XDG_CACHE_HOME`, `XDG_DATA_HOME`, `~/.cache/opencode`, `~/.local/share/opencode` for stale `@heidi-dang/flowdeck` entries while preserving unrelated plugin caches.
- **Duplicate Plugin Detection & Repair**: Detects duplicate FlowDeck loading across `~/.opencode/package.json` and `opencode.jsonc`, preserves canonical source, removes redundant registrations, and repairs invalid entries.
- **Runtime Identity Mismatch Protection**: Doctor checks verify config loading agrees with executing runtime module, flagging `FLOWDECK_RUNTIME_IDENTITY_MISMATCH`.
- **State Machine Integrity**: Enforces strict `DISCOVERED` -> `BACKED_UP` -> `CLEANED` -> `CLEAN_VERIFIED` -> `INSTALLED` -> `CONFIGURED` -> `RESTART_REQUIRED` -> `RUNTIME_VERIFIED` -> `DOCTOR_VERIFIED` -> `HEALTHY` lifecycle.

## Compatibility & Requirements

- **Node.js**: `>=20.0.0`
- **OpenCode**: `>=1.4.0`
- **FDX engine**: `^0.1.0`
- **NPM Release Channel**: `next` (`npm install -g @heidi-dang/flowdeck@next`)
- **Caveats**: Active steering instruction updates require agent iteration boundary; subagent delegation depth capped at 1 level.

## Upgrade Instructions

### Clean Install / Fresh Setup
```bash
npm install -g @heidi-dang/flowdeck@next
flowdeck clean-install
flowdeck doctor
```

### Upgrading from v1.x or v2.0.0-alpha.x
```bash
npm install -g @heidi-dang/flowdeck@next
flowdeck clean-install --repair
flowdeck doctor
```

Note: If Doctor reports `RESTART_REQUIRED`, restart the OpenCode application/daemon to reload the updated plugin bundle into memory.
