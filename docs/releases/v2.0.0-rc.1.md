# FlowDeck v2.0.0-rc.1

Date: 2026-08-14
Status: **RELEASE CANDIDATE (RC.1)**, published under `next` npm dist-tag.

> **Caution**: This is a Release Candidate for evaluation and pre-release testing. It is published on the `next` npm channel and is not yet marked as `latest` stable production.

## Overview

FlowDeck v2.0.0-rc.1 is the culmination of the major v2 runtime evolution, featuring the Heidi persistent agent ecosystem, durable multi-agent parallel execution engine, productionized installer & runtime identity verification, and comprehensive state machine lifecycle safety.

---

## Key Features & Highlights

### 1. Major Heidi v2 Persistent Agent Subsystems
- **Persistent Memory Architecture**: Hierarchical USER, AGENT, and REPO persistent memory scopes with hot-budget indexing and SQLite FTS5 cross-session recall (`/fd-memory`, `/fd-recall`).
- **Evidence-Backed Learning Runtime**: Session evidence capture (`/fd-learn-from-session`, `/fd-learn`, `/fd-learning`), confidence scoring, human/automatic review policies, and progressive loading for versioned learned skills.
- **Governed Tool Pipelines & Scheduler**: Durable background scheduler (`/fd-schedule`) and governed tool call pipelines with bounded iteration, execution timeouts, and audit trails.
- **Runtime Identity Verification**: Self-reporting plugin identity (`.flowdeck/runtime-self-report.json`), source path verification (`file`, `npm-cache`, `package`), and Doctor mismatch detection.

### 2. Parallel Execution Engine
- **Durable Multi-Agent DAG**: Dependency-aware task execution DAG with topological scheduling, failure isolation, and atomic state snapshot persistence.
- **Adaptive Concurrency & Reservations**: Token budget management with per-child reservations, dynamic concurrency tuning, and worktree file isolation.
- **Restart Recovery**: Interrupted parallel workstreams resume automatically from SQLite checkpoint state.

### 3. Hardened Installer & Duplicate Load Repair
- **Legacy & Cache Discovery**: Automatic detection of stale npm caches (`~/.cache/opencode`, `~/.local/share/opencode`, XDG paths) and duplicate plugin load declarations (`~/.opencode/package.json` + `opencode.jsonc`).
- **Safe Selective Cleanup & Backup**: Automated timestamped configuration backup, selective removal of stale FlowDeck cache entries without touching third-party OpenCode plugins, and rollback on failure.
- **Restart-Required Lifecycle**: Explicit distinction between `CONFIG_CHANGED` and `RUNTIME_RELOADED` with clean `RESTART_REQUIRED` state transitions.

## System Requirements & Compatibility

| Requirement | Specification |
| :--- | :--- |
| **Node.js** | `>= 18.0.0` (Recommended: Node 20+ LTS) |
| **OpenCode** | `>= 0.2.0` |
| **Package Manager** | `npm` or `bun` |
| **NPM Channel** | `next` (`@heidi-dang/flowdeck@next`) |

### Known Caveats & Limitations
- **Per-Child Model Routing**: Dynamic model routing operates at the specialist level; per-child prompt-level model overrides within a single subagent invocation are unsupported.
- **Active Steering**: Real-time mid-execution prompt steering is advisory in shadow mode; enforce mode requires strict step boundary completion.
- **Provider Tool-Calling Differences**: Certain non-Anthropic providers may exhibit varied tool call parameter serialization; fallback sanitization is enabled automatically.

## Upgrade Instructions

### Upgrading from v1.x (`v1.0.3` or earlier)
```bash
# 1. Update global CLI / run clean installer from next dist-tag
npx @heidi-dang/flowdeck@next install

# 2. Verify installation & runtime identity
flowdeck doctor
```

### Upgrading from Alpha (`v2.0.0-alpha.*`)
```bash
# 1. Re-run installer to clean stale alpha cache and update plugin config
npx @heidi-dang/flowdeck@next install --repair

# 2. Restart OpenCode session to load RC.1 runtime
opencode restart  # or restart your terminal/IDE harness
```

### Clean Installation
```bash
# Clean install directly via npx
npx --yes @heidi-dang/flowdeck@next install
```
