# FlowDeck v2.0.9

## Fixed & Hardened

- **Confirmed-Terminal Recovery Invariant**: Eliminated spurious automatic Continue prompts during active execution by removing unsafe fallback of missing `finishReason` to `stop`. Malformed empty completions are now only declared upon confirmed terminal evidence.
- **Preflight Live-State Revalidation**: Added pre-submission revalidation to the recovery timer callback, actively suppressing scheduled continuations if provider, tool, child, or user activity is detected.
- **Causal Generation Correlation**: Recovery generation lifecycle correlates internal prompt IDs to the resulting assistant response, preventing unrelated terminal events from closing active recovery slots.
- **Strict Provenance Lifecycle**: Internal prompt provenance persists indefinitely across all lifecycle events for that message ID, and missing/empty text events are classified as `unknown_user_event` rather than triggering wildcard matches.
- **Leak-Free Cancellation & Single-Flight**: Centralized recovery abort logic ensures `isPendingContinuation` is immediately released when a recovery is cancelled or superseded by a manual user message.
- **Bounded Orphan Recovery Timeout**: Implemented an automatic 2-minute orphan recovery timeout with structured telemetry, preventing deadlocks if OpenCode drops an assistant response.
