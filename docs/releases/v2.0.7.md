# FlowDeck v2.0.7

## Fixed & Hardened

- **Incident-Scoped Heidi Liveness Recovery**: Scoped reasoning-recovery budgets to distinct failure incidents (`MAX_AUTO_CONTINUATIONS_PER_INCIDENT = 3`) rather than a single global session counter, allowing long-running engineering sessions to recover reliably from later independent malformed turns.
- **Progress-Based Incident Closure**: Successful visible assistant progress or valid tool execution promptly clears the recovery counter and marks the incident resolved.
- **Session Emergency Ceiling**: Implemented an overarching session-wide emergency budget (`MAX_AUTO_CONTINUATIONS_PER_SESSION = 50`) providing defense-in-depth against continuous failure loops while accommodating long multi-turn sessions.
- **Visible, Recoverable Recovery Exhaustion**: Preserved `hasUnresolvedTask = true` upon recovery exhaustion, ensuring tasks remain visibly unfinished and readily recoverable via follow-up user prompts rather than silently marked complete or idle.
- **Synchronous Prompt & Replay Safety**: Retained full compatibility with synchronous OpenCode `session.prompt` signatures and preserved robust provider history sanitation.
