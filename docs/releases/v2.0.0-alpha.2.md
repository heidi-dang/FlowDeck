# FlowDeck v2.0.0-alpha.2 — Release Candidate

Status: prerelease preparation only. This version has not been tagged, published, or released.

## Highlights

- Autonomous execution intelligence with deterministic classification, scoring, routing, delegation plans, and evidence.
- Dependency-aware workstream execution with isolated Git worktrees, durable leases, ownership enforcement, and controlled integration.
- Adaptive token reclaim, bounded redistribution, stall detection, safe termination, and scoped child context on the existing token-budget authority.
- Durable, explainable agent-performance observations and capability-specific eligibility profiles.
- Explicit off/shadow/enforce routing modes with fail-closed readiness and preserved model/provider authority.
- Optional worktree-aware FDX indexing and daemon support with bounded resources and native/TypeScript fallback behavior.
- Unified runtime observability, reproducible B1–B14 benchmarks, restart recovery, concurrency hardening, and security validation.
