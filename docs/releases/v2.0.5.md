# FlowDeck v2.0.5

## Fixed & Hardened

- **Heidi Reasoning Recovery**: Fully bounded auto-continuation for reasoning-only sessions with circuit-breaker protection and provider replay safety (Gemini/Antigravity and Anthropic signed reasoning).
- **Windows Reliability**: Eliminated Windows CI race conditions, safely managing auto-continuation timers and cleanly disposing SQLite database connections during plugin teardown.
- **Cross-Platform Compatibility**: Replaced Unix-specific temporary path assumptions (`/tmp`) with platform-safe temporary workspaces.
- **OpenCode Plugin Hooks**: Fixed `experimental.chat.messages.transform` and `experimental.chat.system.transform` integration.
