# FlowDeck v2.0.0 Release Notes

**Release Date:** August 15, 2026  
**Version:** `v2.0.0`  
**Track:** Stable (`@latest` / `npm install -g @heidi-dang/flowdeck`)  
**Status:** Official Stable Release (Proven RC.1 Runtime Promotion)

---

## Overview

FlowDeck v2.0.0 is the official stable release of the FlowDeck multi-agent engineering runtime for OpenCode.

This release promotes the proven `v2.0.0-rc.1` runtime to npm `latest`. No runtime source code changes or behavior modifications were introduced in this promotion; v2.0.0 provides the exact verified capabilities validated during the candidate track.

---

## Key Features & Capabilities

### Persistent Heidi Runtime
- **Governed Memory**: Multi-scoped persistence (`USER`, `AGENT`, `REPO`) with secret sanitization and schema-driven storage.
- **Cross-Session Recall**: Fast FTS5-backed full-text search across historical conversation archives.
- **Evidence-Backed Learning**: Proposal, review, approval, and versioned skill creation from execution lessons.
- **Governed Tool Pipelines**: Declarative execution pipelines with token limits, duration budgets, and execution boundaries.
- **Durable Scheduling**: Subcommand-backed interval/cron schedule management with atomic claiming and execution logs.

### Durable Adaptive Parallel Engine v2
- **Process Isolation**: Multi-specialist parallel DAG runs executed in isolated environments.
- **High Concurrency & Real Overlap**: Verified simultaneous execution of independent specialist tasks with bounded worker counts.
- **Restart Durability**: Complete state, schedule, and memory survival across full isolated OpenCode process restarts.

### Native FDX & Fallback Engine
- **High-Performance Code Intelligence**: Native Rust FDX binary integration with automated fallback to TypeScript implementation when needed.
- **Symbol & Impact Analysis**: Fast symbol search, dependency graphing, outline extraction, and symbol-aware git diffs.

### Enterprise Governance & Diagnostics
- **Automated Health Check**: `flowdeck doctor` checks runtime environment, configuration consistency, contracts, and FDX availability.
- **Installer Hardening**: Reliable clean installation, duplicate registration detection, and self-healing.
- **Schema Governance**: Version 11 SQLite schema migration pipeline with explicit table, index, and trigger assertions.

## Installation & Upgrade Instructions

### New Installation

To install official FlowDeck v2.0.0 globally:

```bash
npm install -g @heidi-dang/flowdeck
flowdeck install
flowdeck doctor
```

Or install explicitly via the `@latest` tag:

```bash
npm install -g @heidi-dang/flowdeck@latest
```

### Upgrading from FlowDeck v1.x

1. Update the global package:
   ```bash
   npm install -g @heidi-dang/flowdeck@latest
   ```
2. Run the clean installation and migration utility:
   ```bash
   flowdeck clean-install
   ```
3. Verify system health:
   ```bash
   flowdeck doctor
   ```

### Upgrading from v2.0.0-rc.1

Users on the prerelease candidate track (`v2.0.0-rc.1`) can update to stable `v2.0.0`:

```bash
npm install -g @heidi-dang/flowdeck@latest
flowdeck install
flowdeck doctor
```
