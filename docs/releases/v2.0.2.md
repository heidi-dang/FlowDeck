# FlowDeck v2.0.2 Release Notes

**Date:** August 16, 2026  
**Version:** `v2.0.2`  
**Track:** Stable (`@latest`)

---

## Executive Summary

FlowDeck v2.0.2 is an official hotfix release extending FlowDeck v2.0.1 with critical runtime reliability, Heidi execution policy normalization, and recoverable guard error handling.

This release ensures that FlowDeck governance blocks an invalid or unsafe tool call without terminating Heidi's session or causing the assistant turn to stall.

---

## Key Improvements & Bug Fixes

### 1. Recoverable Guard Error Handling & Autonomous Session Continuation
- **Structured Feedback**: FlowDeck guard blocks emit machine-readable `RecoverableFlowDeckBlockError` feedback (`[FlowDeck Guard Notice - Action Required]`) rather than unhandled raw errors.
- **Autonomous Recovery**: Heidi receives structured guidance, remains active in the same session, and autonomously chooses another valid tool or approach without requiring manual user intervention ("continue" prompts).
- **Deduplicated Recovery**: Session auto-continuation is capped per block signature to prevent infinite recovery loops.

### 2. Heidi Primary Execution Policy & Alias Normalization
- **Unified Identity**: `heidi` and the compatibility alias `orchestrator` resolve to the exact same canonical primary direct-execution identity.
- **Direct Execution Preserved**: `OrchestratorGuard` no longer applies deny-by-default coordinator restrictions to `heidi` or `orchestrator` sessions.

### 3. Read-Only GitHub CLI (`gh`) Inspection
- **Read-Only Inspection**: `gh api` GET requests, `gh repo view`, `gh pr view`, `gh run view`, `gh issue view`, and `gh search` are classified as `read` operations and allowed directly for Heidi.
- **Mutating Protection**: Mutating/destructive `gh` operations (`gh api -X DELETE`, `gh pr create`, `gh release create`) remain protected by governance policy.

### 4. Planning Workspace State Model & Orphan Recovery
- **Granular Status**: `planningWorkspaceStatus` classifies workspace states (`absent`, `incomplete_orphaned`, `valid_no_active_plan`, `active_unconfirmed`, `active_confirmed`, `corrupt_stale`).
- **Orphan Directory Safety**: Empty or incomplete planning directories lacking `STATE.md` no longer block file edits.
- **Recoverable Unconfirmed Plan Gate**: Unconfirmed active plans produce a recoverable approval workflow instead of killing the session.

### 5. Loop Guard `fdx-read` Redirection
- **Read Tool Normalization**: `fdx-read`, `fdx-search`, `fdx-grep`, `fdx-outline`, `fdx-impact`, `fdx-batch` are explicitly normalized.
- **Non-Terminal Redirection**: Repeated identical reads trigger machine-readable guidance (`Use output from previous call`, `Inspect different file`, `Proceed to next step`), redirecting Heidi without ending the session.

### 6. FlowDeck Telemetry & Workspace Ignored State
- **Clean Git Status**: `.flowdeck/`, `.codebase/`, and `.fd-plan/` state/telemetry directories are automatically appended to `.gitignore` on plugin initialization if not already present.
