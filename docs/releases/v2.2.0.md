## Heidi Active Parallel Coordination

FlowDeck v2.2.0 introduces **Heidi Active Parallel Coordination** — the root coordinator remains productive while specialist children execute concurrently, and integrates completed child results incrementally:

- **Root Coordinator Stays Productive**: While all specialist children run, root Heidi continues with non-conflicting coordinator work (`coordinator_work`) instead of idling.
- **Incremental Integration of READY Results**: Results from a completed child are reviewed and integrated immediately — before the last child finishes — with **no global wait-all barrier** (`shouldWaitForAll = false`).
- **Event-Driven + Adaptive Child Reconciliation**: The coordinator tracks child lifecycle events and reconciles state adaptively; a healthy parallel workload polls **0 model turns** (`pollModelTurns === 0`).
- **Fan-out Reconciliation & Root-Depth Provenance Fixes**: Correct effective depth (root 0, child 1), four-child fan-out reconciliation, and provenance preservation for the root coordinator during delegation.
- **Scoped Ownership & Duplicate-Work Protections**: Running coordinator work stays non-conflicting with children; ownership conflicts and duplication events both remain **0**.

## Runtime Self-Audit & Runtime Integrity Scoring

- **Runtime Self-Audit / Runtime Integrity Scoring**: FlowDeck surfaces live runtime integrity scores on live actions and through the WebUI.
- **Visible Per-Action `FlowDeck XX%` WebUI Surface**: Per-action runtime scores rendered in the FlowDeck WebUI dashboard.
- **Current Health & Session Integrity**: Live session-health metrics exposed via the WebUI session-health endpoint.
- **Evidence-Gated Completion Scoring**: Completion is gated on current, SHA-matched verification evidence.
- **Score Isolation from Provider/Model Context**: Runtime integrity scores are kept isolated from provider/model context.

## Runtime & Engineering Improvements

- **Resident FDX Execution / Warm Index Improvements**: FDX native daemon and warm-index execution improvements.
- **Deterministic Shell Fast Lane**: Deterministic fast-lane execution for safe shell commands.
- **Long-Session Recovery / Convergence Protections**: Confirmed-terminal recovery, single-flight continuations, provenance lifecycle persistence, and convergence guard retained.
- **Explicit Real-Runtime Acceptance Command**: `npm run test:live-acceptance` explicitly validates the real OpenCode + Heidi + FlowDeck WebUI integration against actual running processes.
- **CI-Safe Live-Test Separation**: The genuinely live OpenCode/WebUI probes are isolated (and excluded from normal CI and coverage), while the offline Active Coordinator, ancestry, semantic-mutation, and evidence regressions continue to run in the normal test matrix.
