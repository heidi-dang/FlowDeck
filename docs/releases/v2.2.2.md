# FlowDeck v2.2.2

**Release Date:** August 19, 2026

FlowDeck v2.2.2 is a production patch release that fixes the P1 inactive-session watchdog regression reproduced in v2.2.1 while preserving all v2.2.1 shell-failure recovery, Runtime Integrity, Active Parallel Coordination, DSH, FDX, and provider replay behavior.

---

## 1. Fixed — Inactive-Session Watchdog & Bounded Incident Single-Flight

- **Authoritative Watchdog Eligibility Predicate (`isWatchdogEligible`)**:
  - In v2.2.1, `updateWatchdogState` defaulted `hasUnresolvedTask` to `true` on session observation, causing inactive or completed sessions to remain eligible for watchdog stall recovery.
  - v2.2.2 defaults `hasUnresolvedTask` to `false` and introduces `isWatchdogEligible(state)`, which strictly requires `hasUnresolvedTask === true`, `isActiveSession === true`, `isTerminalTask !== true`, `recoveryExhausted !== true`, and no active provider, tool, child, continuation, or user turns in flight.
  - Completed, inactive, idle, cancelled, failed-final, and superseded sessions are explicitly rejected from watchdog eligibility.

- **Terminal Lifecycle Cleanup**:
  - `session.completed` and `session.error` events deterministically set `hasUnresolvedTask: false`, `isActiveSession: false`, `isTerminalTask: true`, and `isPendingContinuation: false`.
  - Completed sessions retained indefinitely in memory/registry remain permanently watchdog-ineligible.

- **Watchdog Incident Single-Flight & Deduplication**:
  - Added `inFlight: boolean` tracking to `WatchdogIncidentState`.
  - `confirmStall` sets `inFlight = true` when issuing a recovery directive and suppresses duplicate prompt injections while `inFlight` is active across repeated timer ticks.
  - Added `clearInFlight` and `markSuperseded` to handle user turns and directive completions cleanly.

- **Preservation of Legitimate Active Stall Recovery**:
  - Legitimate active stalls with unresolved executable work continue to receive single-flight bounded recovery (1 first directive, <=1 alternate directive, transitioning to `STALLED_UNRECOVERED` on exhaustion without infinite nag loops).

- **Preservation of v2.2.1 Shell Failure & Runtime Integrity**:
  - All v2.2.1 non-zero exit code preservation, in-place WebUI updates, and Runtime Integrity scoring remain fully functional.
