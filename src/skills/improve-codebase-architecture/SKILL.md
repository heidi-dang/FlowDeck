# Improve Codebase Architecture Skill

Analyzes project architecture for deepening opportunities, code duplication, and modular boundaries.

## When to Activate

Activate whenever:
- Auditing codebase health or technical debt
- Refactoring complex service modules or circular dependencies
- Preparing architectural recommendations for major upgrades

## Architecture Review Protocol

1. **Modularity Audit**: Check module boundaries, interfaces, and export surfaces.
2. **Dependency Mapping**: Detect tight coupling, circular imports, or duplicate utility patterns.
3. **Actionable Recommendations**: Present prioritized improvement steps with clear trade-off analysis.
